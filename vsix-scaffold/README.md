# Local Skills Bundle

9 local skills (cpolar, ddddocr, knowbase-ingest, nezha, scop, wct, yg, yw, zcm) with one-click install to project `.trae/skills` on open.

## Features

- **Auto-install on workspace open**: copies 9 bundled skills into `<workspace>/.trae/skills/`
- **Manual install command**: `Skills Bundle: Install to Current Workspace`
- **Update from repo command**: `Skills Bundle: Update from Local Repo`

## Installation

1. Open Extensions panel in TraeCode / VS Code
2. `...` menu -> **Install from VSIX...**
3. Select `local-skills-bundle-1.0.0.vsix`
4. Open a workspace, skills auto-install to `.trae/skills/`
