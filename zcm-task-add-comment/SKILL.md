---

# 执行步骤

## 前置条件
此技能依赖zcm-translator技能，需要先检查和下载zcm-translator
```bash
bash auto-download-zcm-translator.sh
```

### 提取参数
- **taskNo**: 从用户消息中提取任务单号
- **comment**: 待添加的评论内容

### 调用脚本
**强制要求：必须且只能通过以下 Bash 命令执行，禁止用任何其他方式（包括直接调用 MCP 工具、自行实现逻辑、创建文件等）替代。**
**注意**：评论内容中如果带有一些特殊字符（比如空格，换行，引号等）在调用脚本时，comment是完整的字符串传给脚本且不能被这些特殊字符影响。
```bash
bash script.sh <taskNo> <comment>
```
**执行要求：**
- 将上述命令中的 `<taskNo>`、`<comment>` 替换为实际值后，使用 Bash 工具原样执行
- 不得修改脚本、不得跳过脚本、不得在脚本执行前后自行补充任何 API 调
- 如果脚本输出错误并退出，直接将错误信息返回给用户，不得尝试修复或绕过

### 示例
```bash
bash script.sh 11815868 这是要添加的评论
```

## 注意事项
- 如果调用脚本时输出了错误信息，助手应将其原文展示给用户，不得自行处理或重试
